Definitions, privacy & sharing

Revenue is the sum of won deal values in USD. It is not recognized revenue, MRR, or ARR. Deals won counts status=won. Average won deal divides total won value by won count; it is never an average of group averages. Win rate excludes open deals. Month uses close_date (expected close date for open rows). Prior-month comparisons use the same filters; missing data is not treated as zero performance.

CSV/TSV only: export XLSX from Excel or Sheets as CSV UTF-8 first. Amounts must be plain USD numbers, dates YYYY-MM-DD, statuses won/lost/open. One unique row per deal; no multi-product allocations or mixed currencies. Invalid rows block import with an error; nothing is silently dropped. Limit: 2 MB and 10,000 deals.

Files remain in memory, with no analytics, external assets, storage, or automatic network upload. Clear data or refresh to reset. Export creates a standalone HTML report with aggregates and group names, excluding raw rows and deal IDs. Share the report through your team's approved private channel, or print it to PDF. Reports contain confidential sales data; the public code repository contains synthetic data only.
